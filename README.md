# Robot Arm Sorter

This project is a machine-vision pipeline for a 3-DOF robotic arm sorter. It reads a camera feed, detects nuts, bolts, and washers with YOLO, refines detections with OpenCV, converts pixel locations to millimetres, and computes inverse kinematics for the robot arm.

The repo is intended to be run end-to-end from a fresh clone.

---

## What you need

- Git
- Python 3.10+
- A webcam or IP camera stream
- A terminal

---

## 1) Clone the repo

```bash
git clone <your-repo-url>
cd robot_arm_sorter
```

---

## 2) Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

---

## 3) Install dependencies

```bash
pip install --upgrade pip
pip install ultralytics flask opencv-python numpy
```

If you want to use the Kaggle download helper as well, install:

```bash
pip install kagglehub
```

---

## 4) Confirm the dataset is present

This project expects the dataset folder to already exist in the repo root, for example:

```text
Nuts and Bolts.v1i.yolov8/
└── data.yaml
```

If it is missing, fetch it or restore it from your repo copy before training or running the app.

You can also use the helper script:

```bash
python download_data.py
```

That script downloads the dataset source using Kaggle Hub.

## 6) Train the model (if needed)

This repo is built around a custom YOLO dataset. If the model is not already present, train one:

```bash
python train_yolo.py
```

The training script uses:

```python
model = YOLO("yolov8n.pt")
```

and then trains on the dataset in:

```python
/home/azad/CODE/projects/robot_arm_sorter/Nuts and Bolts.v1i.yolov8/data.yaml
```

If your repo is cloned somewhere else, update that path to match your local checkout.

After training, copy the generated weights into the repo root:

```bash
cp runs/detect/train/weights/best.pt best.pt
```

---

## 7) Inspect class IDs

If labels look wrong or the app shows numbers instead of object names, run:

```bash
python show_classes.py
```

This creates example crops in `class_preview/` so you can map numeric class IDs to real labels such as `nut`, `bolt`, and `washer`.

Then update the map in `app.py`:

```python
CLASS_NAMES = {
    "2": "Bolt",
    "4": "Nut",
}
```

---

## 8) Start the app

From the project root:

```bash
python app.py
```

Then open in a browser:

```text
http://localhost:5000
```

The dashboard should show:

- live video stream
- object detection overlays
- labels and positions
- inverse-kinematics info for each detected object

---

## 9) Configure the camera

Edit the stream URL in `app.py`:

```python
VIDEO_URL = "http://192.0.0.4:8080/video"   # use 0 for a laptop webcam
```

Common values:

- `0` for a laptop webcam
- `"http://<phone-ip>:8080/video"` for IP Webcam
- a custom RTSP or local stream URL

If the camera is unavailable, the app retries automatically.

---

## 10) Runtime behavior

The app works in two modes:

1. YOLO mode — if `best.pt` is available and loads correctly
2. Fallback mode — if the model is missing, it automatically runs a classical OpenCV contour detector instead

The fallback mode is useful for debugging, but the trained YOLO model is the intended production mode.

---

## 11) Calibration and tuning

For real robot use, you will likely need to adjust these values in `app.py`:

- `PIXEL_TO_MM`
- `BASE_U_FRAC`
- `BASE_V_FRAC`
- `L1`, `L2`, `L3`

These values need to match your camera placement and arm geometry.

---

## 12) Troubleshooting

### App won’t start

Check whether the virtual environment is active and dependencies are installed:

```bash
python -c "import flask, cv2, numpy, ultralytics; print('ok')"
```

### Camera is blank or not connecting

- confirm `VIDEO_URL`
- try a local webcam with `0`
- test the stream in a browser first

### No detections

- confirm the dataset exists
- verify `best.pt` exists if you want YOLO mode
- run `show_classes.py` to verify class mapping

### Labels look wrong

Update `CLASS_NAMES` in `app.py` to the correct numeric-to-name mappings.
